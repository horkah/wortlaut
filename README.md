# wortlaut
Personalisierte Spracherkennung für Menschen, an denen Standardmodelle scheitern: Dialekt, starker Akzent, Dysarthrie. wortlaut sammelt Sprachproben, feintuned daraus ein eigenes Modell und macht Diktieren möglich — vorlesen, danebengegangene Stellen antippen, neu einsprechen. FastAPI + Svelte, selbst hostbar, DSGVO-fest.
